# My personal website, podypodpod.github.io

Live at [podypodpod.github.io](https://podypodpod.github.io). Just a little homepage and my CV.

## Where stuff lives

- `index.html` - homepage bio
- `cv.md` - the CV ("Stuff I've done")
- `_config.yml` - site settings like email, description and link preview info
- `_includes/` and `_layouts/` - page bits and templates

## Running it locally

It's a plain Jekyll site, so with Ruby installed:

```
gem install jekyll jekyll-sitemap
jekyll serve
```

Then open http://localhost:4000. Pushing to `master` publishes it via GitHub Pages.
